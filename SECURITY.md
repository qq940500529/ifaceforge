# Security

To report a vulnerability in IfaceForge, use [GitHub private vulnerability reporting](https://github.com/qq940500529/ifaceforge/security/advisories/new).

Include the affected version, operating system, reproduction steps using a test project, and the expected and observed impact. Remove credentials and personal data from logs. Public issues and Discussions are appropriate for ordinary product bugs and questions.

IfaceForge receives security fixes on its maintained desktop release line. Update to the newest release listed in [GitHub Releases](https://github.com/qq940500529/ifaceforge/releases).
