# IfaceForge 桌面版规格

[桌面方案](desktop-plan.md) · [界面审计](desktop-ui-audit.md) · [发行与验收](release.md) · [v0.1.0 规格](https://github.com/qq940500529/ifaceforge/blob/v0.1.0/docs/development-spec.md)

IfaceForge 是可独立安装的本地 Git 多项目工作台。桌面版建立独立的数据格式，沿用技术预览中的目录、HTTP、MCP、技能、测试、Wiki 和 CLI 能力。

| 需求 | 桌面版验收 |
| --- | --- |
| R01 / A01 | Windows、macOS、Linux 对应产物启动。Windows 安装路径可选。原生目录选择支持取消、子目录确认、重复项目去重、失效与重新定位。 |
| R02 / A02 | 本地注册表和每项目 SQLite 独立于源目录。删除应用数据保护源文件，备份和恢复校验项目及完整性。 |
| R03 / A03 | Git 枚举、来源定位、搜索和差异。后台进度真实可见，可取消、隐藏和重开，跨项目保持归属。Windows 扫描调用 Git 时隐藏控制台。 |
| R04 / A04 | HTTP 构造、发送、断言、OpenAPI 文件或 URL 导入、响应和定义导出。 |
| R05 / A05–A06 | stdio 与 Streamable HTTP 连接、发现、动作、取消与进程回收。 |
| R06 / A07 | 技能搜索查看、引用路径边界。 |
| R07 | 可保存 HTTP/MCP 用例、运行顺序套件、检查和导出报告。 |
| R08 / A08 | Wiki 预览、人工说明、Markdown 与 JSON 导出，保护用户已有内容。 |
| R09 / A09 | 桌面实际窗口逐控件操作检查，覆盖详情展开收起、组合操作、双语与窄窗。 |
| R10 / A10–A11 | 可选 `ifg`，共用项目记录、运行和 Schema，JSON 错误码稳定。 |
| R11 / A12 | MIT 开源发布、可复现构建、平台验证与校验值。 |

## 数据和执行边界

渲染器通过沙箱 preload 访问明确列出的 IPC 方法。桌面后台解析项目 ID，按工作树范围读取源码，按项目数据目录更新记录。导出和备份使用系统选择器。扫描在后台线程运行，并在事务提交前检查取消状态。独立项目之间的扫描可以并发。

开发和可选 CLI 使用受支持的 Node.js LTS。Electron 及构建工具按锁文件版本安装。平台支持范围应以对应发行的实际验证结果为准。
