# 接口工坊使用手册

## 安装和项目

| 系统                | 安装                                                                                                                                 | 应用数据                                      |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------- |
| Windows x64         | 运行 EXE 安装向导，可选安装目录、开始菜单和桌面快捷方式。                                                                            | `%LOCALAPPDATA%\IfaceForge`                   |
| macOS Apple Silicon | 打开 DMG，把 IfaceForge 拖到有写入权限的目录，再打开应用。                                                                           | `~/Library/Application Support/IfaceForge`    |
| Linux x64           | 为 AppImage 添加执行权限后运行，或使用 `sudo apt install ./<文件名>.deb` 安装 DEB，或用 `sudo dnf install ./<文件名>.rpm` 安装 RPM。 | `${XDG_DATA_HOME:-~/.local/share}/ifaceforge` |

安装资产和实际测试环境见对应的 [Release](https://github.com/qq940500529/ifaceforge/releases)。从源码运行请使用开发指南。程序使用 Git 处理本机项目，Git 必须在应用进程的 `PATH` 中。

### Windows 交互与静默安装

双击 EXE 打开向导。选定安装目录后，在 **快捷方式** 页分别选择开始菜单和桌面。默认勾选开始菜单，桌面默认不勾选。两项都可取消，安装后可从安装目录打开 `IfaceForge.exe`。

安装期间，**安装详情** 页显示进度、实际步骤和逐文件记录。文件写入后会记录操作和相对路径。安装结束后仍可查看记录，右键详情列表可复制，再按向导按钮继续。

自动化使用同一个 EXE。以下 PowerShell 示例为当前用户安装，等待安装程序退出并检查退出码。

```powershell
$installer = (Resolve-Path '.\IfaceForge-0.3.0-preview.5-win-x64.exe').Path
$install = Join-Path $env:LOCALAPPDATA 'Programs\IfaceForge'
$result = Start-Process -FilePath $installer -ArgumentList "/S /currentuser /STARTMENU=1 /DESKTOP=0 /D=$install" -Wait -PassThru
if ($result.ExitCode -ne 0) { throw "IfaceForge 安装失败，退出码 $($result.ExitCode)" }
```

`/S` 启用静默安装。`/STARTMENU=0|1` 和 `/DESKTOP=0|1` 分别禁用或启用快捷方式，省略时采用向导的默认值。显式禁用会移除该安装范围内已有的对应 IfaceForge 快捷方式。提供 `/D=` 时使用绝对路径并放在参数末尾，路径含空格时也不加引号。静默安装完成后由调用者决定是否启动应用。

### 添加项目

点击 **添加项目** 选择目录。项目菜单切换工作树，路径可帮助区分同名目录。**管理项目** 可以移除项目、重新定位已移动的原工作树或删除应用数据。从列表移除的项目可以通过选择原目录重新打开。删除应用数据会清除该项目的扫描、环境、用例、运行记录和 Wiki 笔记。

## 扫描和任务

首次扫描默认检查 Git 跟踪的文件。需要纳入尚未跟踪的文件时，可在 **本地设置** 配置扫描。支持 OpenAPI、MCP 离线能力清单、`SKILL.md`，以及部分 Express、FastAPI 和 JavaScript／TypeScript MCP 源码识别。声明格式与测试示例见 [开发指南](developer-guide.md)。

## 选择和比较版本

1. 在顶栏的 **浏览版本** 选择分支或标签。在 **版本与对比** 的网络图里也可以选择任意提交，然后点击 **浏览此提交**。
2. 用顶栏选择两条分支，或从图中把两个提交设为基准和目标。点击 **比较**，可按 API、MCP、技能、文件或诊断查看结果。
3. 展开变更详情，切换统一视图或并排视图，打开基准及目标对应的源文件。需要以共同祖先作为起点时，在结果里选择并应用对应的提交。

网络图先读取当前分支最近一页的提交元数据。使用分支搜索、**显示更多引用** 或 **显示更多** 扩展范围。扫历史文件时只读取当前选择的版本，对比只扫描两个有效端点，已经扫描的相同提交可复用。切换浏览版本保留当前工作区和暂存区，运行 HTTP 或 MCP 测试使用用户选择的实际服务。

扫描浮窗可收起并重新打开。枚举完成后显示已处理和总数。取消扫描会保留上一个完整快照。**任务** 可查看其他项目的扫描和运行，切换当前项目不会改变已启动任务的所属项目。打开目录可筛选类型、来源和差异，并查看正文、定义或本地源码。

扫描出现警告或错误时，从浮窗或 **任务** 点击 **查看诊断**。列表可按级别筛选。每条记录包含诊断码、消息和已知的文件位置，可逐条复制或复制全部。

## 调试和复用

- **HTTP API** 可从工作树内的 OpenAPI 文件或 HTTP(S) URL 导入接口。选择已有接口或新建请求，填入目标、参数、请求头与正文。通过环境使用相对路径以及变量。预览请求目标、发送请求、查看实际响应及断言，或保存为测试用例。
- **MCP** 支持离线查看声明，也可临时启动仓库中的 stdio 和本机 Streamable HTTP 服务。隔离发现与测试结束后自动回收实例。工具、资源、资源模板和提示词仍可保存为用例。见 [MCP 测试指南](mcp.md)。
- **测试** 可编辑用例、配置顺序套件、指定环境、执行和导出报告。运行历史独立于当前编辑中的内容。
- **Wiki** 选择快照并预览，在总览中按 HTTP API、MCP 和技能浏览，或在页面目录中搜索。可展开导出变更、冲突和未匹配的说明。生成后包含有相对链接的 Markdown 和 `catalog.json`。手写说明保存在项目数据库附属目录。
- **本地设置** 支持项目配置、环境、备份、恢复和运行记录清理。备份恢复要求原项目标识。需要凭据时在环境中引用系统环境变量，例如 `{"env":"MY_API_TOKEN"}`，再从设有该变量的进程启动工作台。

应用语言在 **偏好设置** 中切换。CLI 用法见 [命令参考](cli.md)。

长列表可独立滚动。宽屏可在右侧同时阅读详情，窄屏点选后直接定位到详情，可用 **返回列表** 回到原位置。技能、Wiki 和开发指南的预览支持 GitHub Markdown 表格、任务列表、删除线与脚注。应用版本、许可证与致谢位于 **偏好设置 → 关于 IfaceForge**。
