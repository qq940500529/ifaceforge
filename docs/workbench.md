# 接口工坊使用手册

## 安装和项目

| 系统                | 安装                                                                                                                                 | 应用数据                                      |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------- |
| Windows x64         | 运行 EXE 安装向导，可选有写入权限的目录。从开始菜单打开 IfaceForge。                                                                 | `%LOCALAPPDATA%\IfaceForge`                   |
| macOS Apple Silicon | 打开 DMG，把 IfaceForge 拖到有写入权限的目录，再打开应用。                                                                           | `~/Library/Application Support/IfaceForge`    |
| Linux x64           | 为 AppImage 添加执行权限后运行，或使用 `sudo apt install ./<文件名>.deb` 安装 DEB，或用 `sudo dnf install ./<文件名>.rpm` 安装 RPM。 | `${XDG_DATA_HOME:-~/.local/share}/ifaceforge` |

安装资产和实际测试环境见对应的 [Release](https://github.com/qq940500529/ifaceforge/releases)。从源码运行请使用开发指南。程序使用 Git 处理本机项目，Git 必须在应用进程的 `PATH` 中。

点击 **添加项目** 选择目录。项目菜单切换工作树，路径可帮助区分同名目录。**管理项目** 可以移除项目、重新定位已移动的原工作树或删除应用数据。从列表移除的项目可以通过选择原目录重新打开。删除应用数据会清除该项目的扫描、环境、用例、运行记录和 Wiki 笔记。

## 扫描和任务

首次扫描默认检查 Git 跟踪的文件。需要纳入尚未跟踪的文件时，可在 **本地设置** 配置扫描。支持 OpenAPI 声明、部分 Express 和 FastAPI 源码、TypeScript MCP 开发模式以及 `SKILL.md`。

扫描浮窗可收起并重新打开。枚举完成后显示已处理和总数。取消扫描会保留上一个完整快照。**任务** 可查看其他项目的扫描和运行，切换当前项目不会改变已启动任务的所属项目。打开目录可筛选类型、来源和差异，并查看正文、定义或本地源码。

## 调试和复用

- **HTTP API** 可从工作树内的 OpenAPI 文件或 HTTP(S) URL 导入接口。选择已有接口或新建请求，填入目标、参数、请求头与正文。通过环境使用相对路径以及变量。预览请求目标、发送请求、查看实际响应及断言，或保存为测试用例。
- **MCP** 支持本机 stdio 和 Streamable HTTP。连接后浏览工具、资源、资源模板和提示词，查看定义、运行测试、检查响应和断言，再保存为用例。见 [MCP 测试指南](mcp.md)。
- **测试** 可编辑用例、配置顺序套件、指定环境、执行和导出报告。运行历史独立于当前编辑中的内容。
- **Wiki** 选择快照并预览，可展开变更、冲突和说明。生成后包含 Markdown 和 `catalog.json`。手写说明保存在项目数据库附属目录。
- **本地设置** 支持项目配置、环境、备份、恢复和运行记录清理。备份恢复要求原项目标识。需要凭据时在环境中引用系统环境变量，例如 `{"env":"MY_API_TOKEN"}`，再从设有该变量的进程启动工作台。

应用语言在 **偏好设置** 中切换。CLI 用法见 [命令参考](cli.md)。
